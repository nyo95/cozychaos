# ImageGen prompts

These assets were generated with the built-in OpenAI ImageGen workflow. The
current gameplay screenshots were problem references; the accepted ideal mobile
mockup and PixelLab environment were style references.

## Floating island

```text
Use case: stylized-concept
Asset type: replaceable runtime game environment sprite
Primary request: create exactly one side-view floating dream-island platform sprite for Cozy Chaos.
Subject: a long readable grassy arena top with a rich chunky grass lip, tiny restrained flowers, and a deep tapered floating-rock underside. The underside must have large irregular faceted purple stone plates, indigo crevices, selective violet highlights, and substantial depth, ending in one centered broad point.
Style/medium: crisp production-ready 16-bit pixel art matching the wizard and ideal mockup; hard pixel clusters, no blurry vector gradients.
Composition/framing: isolated centered sprite; fully visible; generous padding; final trimmed silhouette about 2.2:1 width-to-height. Top collision surface must be perfectly horizontal from left edge to right edge.
Scene/backdrop: perfectly flat solid #ff0000 chroma-key background for local removal.
Constraints: exactly one platform; no crystals, obstacles, characters, spells, runes, UI, text, stars, clouds, cast shadow, contact shadow, reflection, logo, or watermark. Background must be uniform #ff0000 with no texture or lighting variation. Do not use #ff0000 inside the island.
```

## Crystal obstacle

```text
Use case: stylized-concept
Asset type: replaceable runtime obstacle sprite
Primary request: create exactly one tall magical ice-crystal spike for Cozy Chaos that can safely be clipped to authoritative triangular collision geometry.
Subject: single upright crystal with a perfectly flat wide base, sharp centered tip, and an outer silhouette contained inside a clean isosceles triangle. Use three to five bold internal facets: bright icy-white core edge, cyan face, medium blue face, and deep violet shadow cuts. Strong readable pixel clusters at 40-120 px.
Style/medium: crisp production-ready 16-bit pixel art matching the ideal mockup; no smooth vector look.
Composition/framing: isolated centered vertical sprite, fully visible, generous padding, approximately 1:2.2 width-to-height after trimming. Symmetric enough to flip vertically for ceiling obstacles.
Scene/backdrop: perfectly flat solid #00ff00 chroma-key background for local removal.
Constraints: exactly one crystal; no platform, ground, snow, particles, glow outside its triangle, characters, UI, text, cast shadow, reflection, logo, or watermark. Background must be uniform #00ff00. Do not use #00ff00 inside the crystal.
```

## Rune node

```text
Use case: stylized-concept
Asset type: replaceable runtime spell-matter sprite
Primary request: create exactly one compact magical rune energy node that can be stamped along a player-drawn rune and recolored for cyan or pink teams.
Subject: small round-to-diamond crystalline energy node with an intense white central pixel core, cyan inner facets, pale blue rim pixels, and a restrained dark-indigo outer contour. It must read clearly at 10-24 CSS pixels and look like spell matter, not a water droplet or UI icon.
Style/medium: crisp production-ready 16-bit pixel-art VFX sprite, hard pixel clusters, minimal glow contained close to the core.
Composition/framing: isolated centered single node, fully visible, generous padding, radially balanced and suitable for rotation.
Scene/backdrop: perfectly flat solid #00ff00 chroma-key background for local removal.
Constraints: exactly one node; no line, constellation, rune shape, hand, character, HUD ring, text, platform, particles outside the compact halo, cast shadow, logo, or watermark. Background must be uniform #00ff00. Do not use #00ff00 inside the node.
```
